# 02: 결과를 가로 막대그래프로 표시

**What to build:** 결과 화면의 숫자 리스트를 선택지별 가로 막대그래프(득표율 %, 득표수, 최다 득표 강조)와 총 투표수로 바꾼다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 0건: "아직 투표가 없습니다", 막대는 0%로 깨지지 않음
- [ ] 득표율은 정수 반올림(예: 1/3 → 33%, 2/3 → 67%)
- [ ] 동률 최다 득표는 모두 강조
- [ ] 마감된 투표면 결과 화면에 "최종 결과" 표시
