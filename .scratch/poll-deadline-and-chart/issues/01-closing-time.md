# 01: 마감 시각 설정 + 마감된 투표 거부

**What to build:** 투표 생성자가 `/new`에서 마감 시각(선택)을 넣는다. 목록·투표 화면에 진행 중/마감됨과 남은 시간이 보인다. 마감된 투표는 버튼이 비활성화되고 "마감된 투표입니다"가 표시되며, API도 409로 거부한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `closes_at` 컬럼 마이그레이션 SQL이 `db/schema.sql`에 있고 재실행해도 안전하다
- [ ] 마감 시각 없이 만든 투표는 기존과 동일하게 동작한다
- [ ] 과거 마감 시각은 400으로 거부된다
- [ ] 마감된 투표에 투표 행위 시 서버가 거부하고 득표수는 바뀌지 않는다
- [ ] 마감된 투표 화면: 버튼 비활성화 + 안내 문구 + 결과 보기 링크
