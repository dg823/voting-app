# 01: DB 스키마 + 투표 만들기

**What to build:** 투표 생성자가 `/new`에서 질문과 선택지 2~5개를 입력해 투표를 만들면, 투표 페이지로 이동하고 `/` 목록에 최신순으로 나타난다. 스키마 SQL, DB 연결, polls 모듈, 테스트 하네스(Vitest)가 함께 갖춰진다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `db/schema.sql`이 기존 Neon 테이블과 호환되고 여러 번 실행해도 안전하다
- [ ] 선택지 1개/6개, 빈 질문, 빈 선택지는 서버에서 400으로 거부된다
- [ ] 생성한 투표는 입력한 선택지 순서 그대로 조회된다
- [ ] `/` 목록에 최신 투표가 맨 위에 보인다
- [ ] Vitest 통합 테스트가 실제 DB에서 그린이고, 만든 데이터를 정리한다
