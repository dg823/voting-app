# 02: 투표하기

**What to build:** 투표자가 `/polls/[id]`에서 선택지 하나를 골라 제출하면 득표가 1 늘고 결과 화면으로 이동한다. 같은 브라우저에서 다시 투표하면 거부되고 결과로 안내된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 투표 행위는 해당 선택지의 득표를 정확히 1 올린다
- [ ] 다른 투표의 선택지 ID로 투표하면 거부된다
- [ ] 쿠키가 있는 브라우저의 재투표는 409이고, 투표 페이지 재방문 시 결과로 이동한다
- [ ] 없는 투표 ID는 404 / 찾을 수 없음 화면
