**Status:** ready-for-agent

- [ ] 투표 조회 SQL(목록/상세)의 컬럼·마감 판정식이 한 곳에만 있다
- [ ] 투표 화면과 결과 화면의 "배지 + 마감 시각" 머리 부분이 한 컴포넌트다
- [ ] 목록에 만든 시각과 마감 정보가 함께 보인다
- [ ] 기존 테스트 전부 그린
