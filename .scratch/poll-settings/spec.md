# 스펙: 투표 설정 확장 — 공개 방식, 선택 방식, 결과 공개 시점, 예약 시작/종료

**Status:** ready-for-agent

## 문제

동아리 회장: "임원 선거는 익명이어야 하지만, 회식 참석 조사는 누가 뭘 골랐는지 알아야 해요. 먹고 싶은 메뉴는 여러 개 고르게 하고 싶고요. 선거는 결과가 중간에 보이면 분위기에 휩쓸리니 끝나고 공개했으면 좋겠어요. 투표를 미리 만들어 두고 정해진 시간에 열리게 하고 싶어요."

## 해결

관리자는 투표를 만들 때 다음을 정한다.
1. **공개 방식**: 익명 / 실명. 실명이면 투표자가 이름을 입력하고, 결과에 선택지별 투표자 명단이 보인다.
2. **선택 방식**: 단일 선택 / 복수 선택.
3. **결과 공개 시점**: 항상 / 마감 후. 마감 후 공개면 마감될 때까지 결과가 숨겨지고 마감되면 자동으로 공개된다.
4. **시작 시각**(선택): 이 시각 전에는 "예정" 상태로 투표를 받지 않고, 시각이 되면 자동으로 열린다. 마감 시각에는 기존처럼 자동으로 닫힌다.

## User Stories

1. As a 관리자, I want to 투표를 익명 또는 실명으로 만들고, so that 목적에 맞게 운영한다
2. As a 투표자, I want to 실명 투표에서 이름을 입력하고 투표하고, so that 누가 참여했는지 남는다
3. As a 투표자, I want to 실명 투표에서 이름 없이는 제출할 수 없고, so that 명단이 빠지지 않는다
4. As a 관리자, I want to 실명 투표에서 같은 이름이 두 번 투표하지 못하고, so that 1인 1표가 지켜진다
5. As a 투표자, I want to 실명 투표 결과에서 선택지별 투표자 이름을 보고, so that 누가 무엇을 골랐는지 안다
6. As a 투표자, I want to 익명 투표에서는 이름을 묻지 않고 결과에 이름이 없고, so that 비밀이 지켜진다
7. As a 관리자, I want to 단일 선택 또는 복수 선택 투표를 만들고, so that 질문 성격에 맞춘다
8. As a 투표자, I want to 복수 선택 투표에서 체크박스로 여러 개를 고르고, so that 원하는 것을 모두 표시한다
9. As a 투표자, I want to 단일 선택 투표에서는 하나만 고를 수 있고, so that 규칙이 지켜진다(서버도 거부)
10. As a 투표자, I want to 복수 선택 결과에서 득표율이 투표자 수 기준이라는 안내를 보고, so that 합이 100%를 넘어도 헷갈리지 않는다
11. As a 관리자, I want to 결과를 마감 후에만 공개하도록 정하고, so that 투표 중 결과에 휩쓸리지 않는다
12. As a 투표자, I want to 마감 후 공개 투표에서 투표 뒤 "결과는 마감 후 공개됩니다"와 공개 시각을 보고, so that 언제 볼 수 있는지 안다
13. As a 투표자, I want to 마감 시각이 지나면 따로 조작 없이 결과를 보고, so that 자동 공개된다
14. As a 관리자, I want to 마감 전에도 결과를 미리 보고, so that 진행 상황을 파악한다
15. As a 공격자, I cannot API로 마감 전 숨겨진 결과를 가져올 수 없다
16. As a 관리자, I want to 시작 시각을 정해 투표를 미리 만들어 두고, so that 정해진 시간에 자동으로 열린다
17. As a 투표자, I want to 시작 전 투표에서 "예정" 배지와 시작까지 남은 시간을 보고 투표 버튼은 꺼져 있고, so that 언제 참여할지 안다
18. As a 투표자, I want to 시작 시각이 되면 새로고침 없이 투표할 수 있게 되고, so that 바로 참여한다
19. As a 관리자, I want to 시작 시각이 마감 시각보다 늦으면 거부되고, so that 잘못된 일정이 생기지 않는다
20. As a 관리자, I want to 결과를 마감 후 공개로 하려면 마감 시각이 꼭 필요하다고 안내받고, so that 영원히 숨겨진 결과가 생기지 않는다
21. As a 관리자, I want to 투표가 들어온 뒤에는 선택 방식·공개 방식이 잠겨 있고, so that 기록이 망가지지 않는다
22. As a 투표자, I want to 기존에 만든 투표가 그대로(익명·단일 선택·항상 공개·즉시 시작) 동작하고, so that 달라진 게 없다

## Implementation Decisions

- ADR-0005: `ballots`/`ballot_choices` 추가, `options.vote_count` 카운터 유지, `polls.ballot_count` 추가(기존 투표는 득표 합으로 채움)
- `polls`에 `opens_at`(nullable), `choice_mode`('single'|'multiple', 기본 single), `is_anonymous`(기본 true), `results_after_close`(기본 false)
- 상태는 DB에서 `예정 | 진행 중 | 마감됨` 하나로 계산(기존 `isClosed` 대체)
- 투표 행위 입력: 선택지 ID 목록 + (실명이면) 이름 1~20자. 결과: `ok | not_found | invalid_option | not_open | closed | name_required | name_taken`
- 투표 조회 API는 결과가 숨겨진 상태면(관리자 제외) 득표·투표자 수·명단을 응답에서 뺀다
- 검증: 시작 < 마감, 마감 후 공개면 마감 시각 필수, 새 시작 시각은 과거 불가(기존 값 유지는 허용)
- 수정: 투표자 수가 1 이상이면 선택 방식·공개 방식 변경 거부

## Testing Decisions

- polls 모듈(실제 DB): 예정 투표 거부, 시작 시각 이후 투표 가능, 복수 선택 집계와 투표자 수, 단일 선택에 2개 거부, 실명 이름 필수·중복 거부·명단 조회, 투표 후 방식 잠금
- 검증 순수 함수: 일정 순서, 마감 후 공개 조건, 설정 값
- 결과 순수 함수: 복수 선택 득표율(투표자 수 분모), 결과 공개 여부 판정

## Out of Scope

- 본인 인증(이름 도용 방지), 복수 선택 최대 개수 제한, 투표자 명단 비공개 옵션, 알림
