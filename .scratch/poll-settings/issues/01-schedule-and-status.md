# 01: 예약 시작 + 상태(예정/진행 중/마감됨)

**What to build:** 관리자가 시작 시각을 정할 수 있고, 시작 전 투표는 "예정" 배지·남은 시간·꺼진 버튼으로 보이며 서버도 거부한다. 시작 시각이 되면 자동으로 열린다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 스키마 마이그레이션(모든 새 컬럼·테이블)이 `db/schema.sql`에 있고 재실행해도 안전하다
- [ ] 시작 시각이 마감 시각보다 늦으면 400
- [ ] 예정 투표에 투표 행위 시 거부, 득표 변화 없음
- [ ] 목록·투표·결과 화면에 예정/진행 중/마감됨 표시
