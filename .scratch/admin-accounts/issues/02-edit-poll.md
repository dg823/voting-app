# 02: 관리자가 투표 수정

**What to build:** 관리자가 투표 화면의 "수정"에서 질문, 선택지 이름, 마감 시각을 고친다. 득표수는 유지된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 수정 내용이 투표·결과 화면에 반영되고 득표는 그대로다
- [ ] 마감 시각을 비우거나 미래로 바꾸면 마감된 투표가 다시 진행 중이 된다
- [ ] 다른 투표의 선택지 ID로는 수정할 수 없다
- [ ] 비로그인 `PATCH /api/polls/[id]` → 401, `/polls/[id]/edit` → 로그인 화면
