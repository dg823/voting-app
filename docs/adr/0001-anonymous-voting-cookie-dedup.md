# v1은 로그인 없는 익명 투표 + 쿠키 기반 중복 방지를 사용한다

동아리용 투표 앱은 "질문 올리고, 고르고, 결과 보기"만 요청받았다. 그래서 투표자 계정과 투표 생성자 권한 없이 누구나 투표를 만들고 익명으로 투표하도록 했다. 중복 투표는 투표별 쿠키로 브라우저당 한 번만 막는다. 쿠키를 지우거나 다른 브라우저를 쓰면 다시 투표할 수 있으므로 신뢰성보다 단순함을 고른 트레이드오프다. 투표자 신원을 데이터 모델에 붙이는 작업(로그인, 서버 측 중복 방지)은 이후 버전에서 따로 추가한다.
