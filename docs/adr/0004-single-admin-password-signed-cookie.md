# 관리자는 공유 비밀번호 하나로 로그인하고, 세션은 서명된 쿠키에 담는다

투표 생성·수정·삭제를 관리자만 할 수 있게 바꾸면서, 관리자 계정 테이블을 두지 않고 환경변수 `ADMIN_PASSWORD` 하나를 모든 관리자가 공유하기로 했다. 동아리 규모에서는 관리자가 한두 명이라 계정 관리 화면·비밀번호 해시 저장 비용이 이점보다 크기 때문이다. 로그인에 성공하면 만료 시각을 `SESSION_SECRET`으로 HMAC 서명한 쿠키(1일)를 발급하고, DB 세션 테이블 없이 서명만 검증한다. 따라서 개별 세션을 강제 로그아웃시킬 수 없고, 필요하면 `SESSION_SECRET`을 바꿔 모든 세션을 한꺼번에 무효화한다. 권한 검사는 화면(페이지)과 API(Route Handler) 양쪽에서 각각 하며, 화면에서 버튼을 숨기는 것은 편의일 뿐 보안 경계는 서버다. 관리자별 개별 계정이 필요해지면 `admins` 테이블과 해시 비밀번호로 옮긴다.
