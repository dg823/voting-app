# 마감 여부는 DB 시각 기준으로, 투표 행위를 기록하는 SQL 안에서 판정한다

마감 시각(`closes_at`, nullable)이 지난 투표는 화면에서 버튼을 비활성화한다. 하지만 클라이언트 검증은 우회할 수 있으므로 서버도 반드시 거부한다. 서버 판정은 "조회 후 검사"가 아니라 `update ... where closes_at is null or closes_at > now()` 한 문장으로 한다. 그래서 조회와 기록 사이에 마감 시각이 지나는 경쟁 상황이 없고, 앱 서버마다 시계가 달라도 DB 시각 하나만 기준이 된다. 화면의 "남은 시간" 표시는 참고용일 뿐이며, 판정의 근거는 언제나 DB다.
