# ORM과 차트 라이브러리 없이 raw SQL과 직접 만든 막대그래프를 사용한다

수업 스택(Next.js + `@neondatabase/serverless`)을 따라 ORM 없이 SQL을 직접 쓴다. 테이블이 두 개뿐이라 ORM의 이점보다 학습·설정 비용이 크기 때문이다. 결과 그래프도 Chart.js나 Recharts 같은 라이브러리 대신 선택지별 가로 막대를 CSS 너비(득표율 %)로 직접 그린다. 선택지가 2~5개인 단일 선택 투표에서는 가로 막대가 비교하기 가장 쉽고, 긴 선택지 라벨도 잘리지 않는다. 또 서버 컴포넌트에서 바로 렌더링되어 번들이 늘지 않는다. 원형·시계열 같은 복잡한 차트가 필요해지면 그때 라이브러리 도입을 다시 검토한다.
